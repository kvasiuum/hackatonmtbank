# Семья в Moby — хакатон МТБанка «Детско-семейный банкинг»

Кликабельный прототип модуля детско-семейного банкинга внутри Moby для рынка Республики Беларусь.

**Запуск:** откройте `prototype/index.html` в браузере. Сборка и сервер не нужны.

## Режимы
Переключатель слева (на телефоне — сверху). Данные общие для всех ролей и сохраняются в браузере.

- **Родитель:** Moby взрослого, вкладка «Семья», запросы детей, лимиты, категории, доступы, задания, карманные деньги, оформление пакета (6 шагов с согласиями).
- **Ребёнок 7–13:** карта (стикер/браслет/пластик), «Попросить», симулятор оплаты, копилки с доплатой родителя +10%, задания, уроки, игра «Распознай мошенника», уровни «Крок».
- **Подросток 14–17:** ЕРИП, переводы друзьям, карта для подписок, собственный заработок и вклад (ст. 26 ГК РБ), аналитика трат, путь к 18.

## Сценарии для демо
1. Ребёнок → «Оплатить» → «Донат в игре» → запрос доступа → Родитель одобряет.
2. Ребёнок → «Магазин игрушек» (дороже 10 BYN) → покупка ждёт подтверждения родителя.
3. Ребёнок → «Задания» → «Сделал!» → Родитель подтверждает → награда и опыт.
4. Ребёнок → «Игры» → уроки / «Распознай мошенника» → новый уровень «Крок» → родителю предложение расширить лимит.
5. «Начать без детей» → Родитель → оформление пакета → новый ребёнок появляется в режиме «Ребёнок».

Банковская защита: азартные игры, ставки и товары 18+ закрыты всегда и не отключаются родителем.
