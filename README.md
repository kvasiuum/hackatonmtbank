# Семья в Moby — модуль детско-семейного банкинга МТБанка

Рабочий модуль для Moby: сервер с API и базой данных и мобильный веб-интерфейс, который встраивается в Moby (WebView или отдельный раздел). Рассчитан на рынок Республики Беларусь.

**Демо:** https://kvasiuum.github.io/hackatonmtbank/ (работает в браузере телефона, смарт-код `1111`). **Презентация:** [`presentation/Moby_Семья_презентация.pptx`](presentation/Moby_Семья_презентация.pptx) — анализ ТЗ, концепция для 7–13 и 14–17 лет, целевая аудитория, конкуренты и наша изюминка, схема работы и пути родителя, ребёнка и подростка по шагам ТЗ на экранах модуля, экономика с пошаговым расчётом и Win-Win, Product Canvas, таблица соответствия ТЗ, демо с QR-кодом и итоговый слайд.

## Запуск

Нужен Node.js 22.5+ (используется встроенный `node:sqlite`, нативных зависимостей нет).

```bash
cd module
npm install
npm start          # собирает интерфейс и поднимает сервер на http://localhost:8080
npm test           # 22 теста: правила авторизации платежей и сквозные сценарии API
npm run dev        # разработка: API на :8080 + Vite на :5173 с горячей перезагрузкой
```

Откройте http://localhost:8080 — это демо-стенд: телефон родителя и телефон ребёнка рядом, данные общие и обновляются вживую. Смарт-код демо-пользователей: `1111`. На телефоне показывается один экран с переключателем «Родитель / Ребёнок».

## Android-приложение

В папке `android/` — приложение на Kotlin. Внутри APK лежит готовый модуль (сборка из `docs/`), поэтому он работает без интернета, а данные семьи хранятся на телефоне.

**Установить.** Каждый пуш собирает APK в GitHub Actions (workflow «Android APK») и публикует его в **Releases** как `build-N`. На телефоне откройте последний релиз, скачайте `MobyFamily-N.apk` и установите: Android один раз попросит разрешить установку из браузера.

**Обновлять.** Просто запушьте изменения: через несколько минут появится новый релиз, а приложение при следующем запуске предложит обновиться. Все сборки подписаны одним демо-ключом (`android/app/demo-keystore.jks`), поэтому новая версия ставится поверх старой, данные сохраняются. Для продакшена ключ нужно перенести в секреты CI.

**Собрать локально.** `cd module && npm run build:pages`, затем открыть папку `android/` в Android Studio и нажать Run (или `./gradlew assembleRelease`).

## Попробовать на Android (GitHub Pages)

В папке `docs/` лежит автономная сборка: API модуля выполняется прямо в браузере телефона (та же логика и те же маршруты, SQLite на WebAssembly), данные хранятся на телефоне.

1. GitHub → репозиторий → **Settings → Pages** → Source: **Deploy from a branch** → ветка с модулем, папка **/docs** → Save.
2. Через минуту откройте на телефоне `https://<ваш-логин>.github.io/hackatonmtbank/` в Chrome (сейчас: https://kvasiuum.github.io/hackatonmtbank/, собирается из `/docs` ветки `claude/charming-mendel-yikjgx`).
3. Меню Chrome → **«Добавить на главный экран»** (или «Установить приложение»): модуль откроется на весь экран, как приложение, и будет работать без интернета.
4. Вверху переключайтесь «Родитель / Ребёнок», кнопка ↺ сбрасывает демо-данные. Смарт-код: `1111`.

Пересобрать после изменений: `cd module && npm run build:pages`.

## Что умеет

**Родитель** (главная и «Продукты» как в Moby, модуль добавлен входом «Семья»)
- При первом входе после обновления — короткий экран «Новое в Moby: Семья», дальше только точки входа: «Семья» на главной, в «Продуктах» и в «Ещё».
- «Семья»: сверху всё, что ждёт ответа (запросы детей с суммой крупно, заявки подростков), ниже дети, быстрые действия, пакет, семейная цель; лента свёрнута.
- Карточка ребёнка: запросы этого ребёнка, траты сегодня против лимита, задания (своё задание, удаление); настройки — в трёх плитках, каждая раскрывает своё меню: «Деньги» (карты, аналитика трат — круговая диаграмма по категориям за месяц, карманные деньги и копилки, страховка и вклад, операции), «Правила» (что можно покупать, лимиты и подтверждение, возможности в Moby, безопасность), «Успехи» (уровень, копилки, доход, скидка «Трать меньше»).
- Добавить ребёнка 7–17 лет: возраст определяет пакет и правовую модель, согласия законного представителя, выбор карты (браслет, стикер, пластик) и цвета, настройка разрешений (режим + отдельные переключатели), приглашение по QR-коду.
- Карты ребёнка (до 3): выпуск виртуальной сразу, физическая — «в доставке» до получения, блокировка, перевыпуск.
- Разрешения: категории покупок, QR-оплата КРОК, ЕРИП, переводы, подписки, копилки, выпуск карт, вход в Moby. Азартные игры и 18+ закрыты банком без возможности отключения.
- Лимиты в день и месяц, порог подтверждения покупок, карманные деньги по понедельникам (автоматически), доплата к копилке, округление сдачи.
- Запросы детей: деньги, доступ, карта, покупка выше порога, лимит, новый уровень, выполненное задание, копилка.
- Задания: экран «Задания» по всем детям — создать своё или готовое, изменить текст и награду, удалить; ребёнок может предложить своё задание с суммой. Задание «Всем детям»: награду получает тот, кто выполнит первым, у остальных оно закрывается (если родитель не принял — снова открыто всем).
- «Списать»: родитель возвращает деньги со счёта ребёнка на любую свою карту; заработок подростка (ст. 26 ГК РБ) хранится отдельно и не списывается. С 16 лет списывать нельзя: кнопки нет, сервер отвечает 403.
- Несколько карт родителя (основная, зарплатная, личная, Халва): перевод ребёнку, одобрение запроса на деньги, награда за задание, карманные и семейная цель списываются с карты, выбранной в карусели миниатюр. Автоплатежи (карманные по понедельникам, плата за пакет, доплата к копилке) берут первую карту, где хватает средств.
- Добавление по номеру телефона: родитель указывает номер ребёнка, ребёнок входит по SMS-коду. Подросток с 14 лет может сам попроситься в семью по номеру родителя; до 14 лет — только через родителя (ст. 25 ГК РБ).
- Пакеты «Семья Старт» (один ребёнок) и «Семья+» (до 4 детей), кешбэк недели у партнёров, семейная цель, лента событий. Демо-семья — на «Семья+». В «Старт» при попытке добавить второго ребёнка открывается шторка «Сначала оформите «Семья+»» с преимуществами пакета; после подключения сразу продолжается добавление ребёнка (проверить: «Семья без детей» → добавить одного → «Добавить ребёнка» ещё раз).
- Двое родителей в семье: у каждого свои карты и свои Манички, оба видят детей. Ребёнок выбирает, у кого попросить деньги; запрос видит и отвечает на него только этот родитель, второму он не показывается.
- Манички с каждой покупки ребёнка: ему 1 за каждый BYN, каждому родителю 1 за каждые 2 BYN — у всех свой счёт (п. 4.3 ТЗ). Ещё родителю: за переводы детям (×2 в «Семья+»), принятые задания и пройденные ребёнком уроки.
- Страхование ребёнка (несчастный случай / спорт, −30% в «Семья+»), вклад «На вырост» от родителя, «Для семьи»: предложения партнёров (развлекательные центры, клиника, кружки) и советы родителям.
- Оспорить операцию из истории: у родителя (свои и детей) и у ребёнка.

**Ребёнок 7–13 / подросток 14–17**
- Вход по коду приглашения или по номеру телефона и собственному смарт-коду.
- «Мега-копилка» у ребёнка 7–13 и у подростка: стеклянная свинка на светлой сцене; сумма — в шторке, а пополнение анимируется на экране копилки, внутри видны монеты и купюры, уровень растёт с каждым пополнением. Когда цель набрана, копилка светится и взрывается (осколки, монеты, конфетти), а накопленное приходит на счёт — можно покупать то, на что копил. Кешбэк недели ребёнку приходит Маничками. В играх — конфетти, анимация совпадений и ошибок.
- Главная ребёнка: сколько ещё можно потратить сегодня, запросы, ближайшее задание, копилка, кешбэк недели; карты и покупки свёрнуты.
- «Трать меньше — получай скидку» (в «Копилках» и «Накоплениях»): месяц делится на 4 недели (1–7, 8–14, 15–21, 22–конец). Если за неделю потрачено меньше, чем за прошлую, каждые сэкономленные 10 BYN дают 1% (0.1% за каждый 1 BYN); первая неделя — точка отсчёта. Проценты за месяц складываются, потолок — 20%. В начале следующего месяца ребёнок выбирает партнёра, и скидка применяется один раз к покупке у него до конца месяца (на экране оплаты у партнёра метка «−X%»). Родитель видит прогресс в «Успехах».
- Оплата картой или по QR через КРОК, «Я потерял карту» (оплата переходит на виртуальную карту). Блокировка карты — только после подтверждения.
- Свои подписи и цвет карт, избранная карта: ею платим по умолчанию, при оплате она первая, можно выбрать другую.
- Копилки, задания, уроки финансовой грамотности и игра «Распознай мошенника» с наградами и уровнями самостоятельности.
- Перевод другу по номеру карты (проверка по алгоритму Луна), с 14 лет — ещё и по номеру телефона. В копилку, семейную цель, на вклад и из заработка — любая сумма, не больше доступной.
- Подросток, вкладки «Главная», «Накопления», «MobyPlay», «Ещё». На главной уровень (ведёт в «Путь к 18»), траты за месяц и кнопка «Платежи» — QR КРОК, ЕРИП, переводы, подписки. «Накопления» — заработок и задания, вклад (ст. 26 ГК РБ), копилки. «Ещё» — урезанная версия взрослого раздела: настройки (скрыть баланс, уведомления, выход), карты, путь к 18, аналитика трат (круговая диаграмма по категориям за месяц, сумма совпадает с итогом), подписки, Манички.
- Ребёнок 7–13, вкладки «Главная», «Копилки», «MobyPlay», «Ещё». Задания — карточкой на главной (с кнопкой «Все») и в «Ещё». В «Ещё» — настройки (скрыть баланс, уведомления, выход), моя карта, задания, покупки, мои запросы, Манички.
- MobyPlay (у ребёнка и подростка): игры «Распознай мошенника», «Карты по памяти» с партнёрами Moby (за 60 секунд, таймер — полоса с бегущим градиентом, последние 10 секунд красная) и «Угадай цену», ниже уроки и предложения партнёров. За верный ответ — вспышка «Верно!» с искрами и монетками. За игры Манички и опыт раз в день.
- Манички ребёнка — бонусы Moby со своим экраном («Ещё» → «Манички» или значок на главной и в MobyPlay): сколько есть, как заработать (покупки картой, игры, уроки, кешбэк недели) и на что потратить — купоны партнёров (код для кассы, сохраняется в «Мои купоны») или обмен на деньги: 100 Маничек = 1 BYN на счёт. Предложение партнёра в MobyPlay открывает шторку: скидка по карте Moby и купон за Манички.

## Пакеты и спецусловия для семьи

| | «Семья Старт» | «Семья+» |
|---|---|---|
| Цена | 0 BYN | 4.90 BYN в месяц; бесплатно, если семья потратила за месяц от 400 BYN; первый месяц бесплатно |
| Дети | 1 | до 4 |
| Карты | виртуальная и стикер | плюс браслет и пластиковая карта |
| Кешбэк недели у партнёров | 5% | 10% |
| Спецусловия | — | Манички ×2 в детских категориях, +1% к вкладу родителя, рассрочка 0% на школьные покупки, страхование ребёнка −30%, бесплатные переводы внутри семьи |

Плата за «Семья+» — не основной доход, а стимул перенести траты семьи в МТБанк: при обычных тратах семьи пакет бесплатен. Кешбэк недели оплачивает партнёр из маркетингового бюджета (как скидку), а банк получает с партнёра комиссию; в понедельник кешбэк за прошлую неделю приходит на счёт ребёнка.

## Экономика

Калькулятор с этими допущениями открывается на стенде кнопкой «Экономика модуля» (на телефоне — «Экономика» в верхней панели); все значения можно менять. Расчёт — `economics()` в `module/server/src/content.ts`.

| Допущение | Значение |
|---|---|
| Семей за первый год | 10 000 |
| Привлечение семьи (реклама в Moby, приветственный бонус) | 25 BYN |
| Физическая карта (выпуск и доставка), берут 60% детей | 10 BYN |
| Детей в семье | 1,6 |
| Траты ребёнка | 90 BYN в месяц |
| Новые траты родителя в МТБанке | 150 BYN в месяц |
| Доход с оборота по картам | 1,2% |
| Остатки семьи (счета детей, копилки, вклады) / маржа | 300 BYN / 8% годовых |
| На «Семья+» / из них платят | 40% / 50% |
| Траты детей у партнёров / комиссия партнёра | 20% / 3% |
| Родителей в семье (Манички у каждого свои) | 1,5 |
| Манички ребёнку за игры и уроки | 40 в месяц |
| Доля Маничек, которую банк оплачивает деньгами | 50% (купоны оплачивают партнёры, часть не тратится) |
| Спецусловия «Семья+» (+1% к вкладу родителя) | 0,50 BYN в месяц на семью в пакете |
| Обслуживание семьи | 1 BYN в месяц |
| Разработка и запуск | 150 000 BYN |

Манички считаются по тем же правилам, что начисляет модуль (1 Маничка = 1 копейка, 100 = 1 BYN): ребёнку 1 за каждый BYN покупок (144 в месяц), каждому родителю 1 за 2 BYN покупок детей (108 на 1,5 родителя) и 1 за 5 BYN переводов детям, ×2 в «Семья+» (40), за игры и уроки (64) — 356 Маничек на семью в месяц, номинал 3,56 BYN; деньгами банк платит половину — 1,78 BYN.

Результат с одной семьи в месяц: доход 7,37 BYN (оборот 3,53, остатки 2,00, пакет 0,98, партнёры 0,86), Манички 1,78, спецусловия 0,20, обслуживание 1,00 — **прибыль 4,39 BYN**. Привлечение семьи с картой 34,60 BYN плюс 15 BYN разработки на семью — **окупаемость 11,3 месяца**, результат первого года по 10 000 семьям около 31 тыс. BYN, за три года — около 108 BYN с семьи (без учёта оттока). Чувствительность: при 5 000 семей — 14,7 месяца, при 20 000 — 9,6; если привлечение стоит 50 BYN — 17; если за пакет никто не платит — 14,5; если все Манички обменивают на деньги — 19; если ребёнок тратит 60 BYN, а не 90 — 12,4.

## Архитектура

```
module/
  server/            Node.js + TypeScript, Fastify, SQLite (node:sqlite), zod
    src/content.ts   справочники: типы карт, пресеты, магазины, ЕРИП, уроки
    src/domain/      authorize.ts — правила авторизации платежа (чистая функция)
    src/service.ts   бизнес-логика семьи
    src/routes.ts    маршруты API без привязки к транспорту (общие для сервера и браузера)
    src/app.ts       Fastify: маршруты, SSE-уведомления, раздача интерфейса
    src/schema.ts    схема БД и демо-данные (node:sqlite на сервере, sql.js в браузере)
    test/            unit- и API-тесты (vitest)
  web/               React + TypeScript + Vite, Inter, иконки Moby и Lucide
    src/local.ts     автономный режим для GitHub Pages: API в браузере, база в localStorage
docs/                готовая веб-сборка: GitHub Pages (PWA) и содержимое APK
android/             Kotlin-приложение: WebView с модулем из APK, проверка обновлений в GitHub Releases
.github/workflows/   сборка APK и публикация релиза на каждый пуш
```

- Суммы хранятся в копейках, время лимитов считается по Минску (UTC+3).
- Баланс не уходит в минус: каждое списание — `UPDATE … WHERE balance >= сумма` с проверкой результата, плюс `CHECK (balance >= 0)` в схеме; при нехватке API отвечает «Недостаточно средств», интерфейс заранее блокирует кнопку и подсказывает.
- Смарт-коды хранятся как scrypt-хеш, вход по Bearer-токену сессии.
- Родитель может управлять только детьми своей семьи; ребёнок — только своими картами и запросами.
- Изменения рассылаются через Server-Sent Events: экран родителя обновляется, как только ребёнок отправил запрос.

### API (основное)

| Метод | Путь | Кто |
|---|---|---|
| POST | `/api/auth/login`, `/api/auth/join` | вход по смарт-коду / по коду приглашения |
| POST | `/api/auth/phone/{start,verify}`, `/api/auth/join-request`, `/api/auth/join-status` | вход по номеру и SMS-коду, заявка подростка в семью |
| GET | `/api/parent/overview`, `/api/parent/children/:id` | родитель |
| POST | `/api/parent/children` | добавить ребёнка |
| PATCH | `/api/parent/children/:id/settings` | разрешения и лимиты |
| POST | `/api/parent/children/:id/{topup,cards,tasks,reissue,allowance}` | родитель |
| POST | `/api/parent/requests/:id`, `/api/parent/join-requests/:id` | одобрить / отклонить запрос или заявку в семью |
| GET, PATCH, DELETE | `/api/parent/tasks`, `/api/parent/tasks/:id` | список, изменение и удаление заданий |
| POST, DELETE | `/api/parent/children/:id/insurance`, POST `/api/parent/children/:id/deposit` | страховка и вклад на ребёнка |
| POST | `/api/disputes` | оспорить операцию |
| POST | `/api/parent/plan`, `/api/parent/intro-seen` | сменить пакет, отметить показ «Что нового» |

## Правовые рамки (РБ)

- До 14 лет ребёнок сам совершает только мелкие бытовые сделки (ст. 25 ГК РБ): карта — дополнительная к счёту родителя.
- С 14 лет счёт на имя подростка с письменного согласия родителя; заработком и вкладом подросток распоряжается сам (ст. 26 ГК РБ).
- Согласия законного представителя и на обработку персональных данных ребёнка (Закон № 99-З) фиксируются в базе.
- КРОК — национальный сервис мгновенных QR-платежей (Нацбанк РБ, ЕРИП); в модуле — способ оплаты с теми же лимитами.

Перед защитой стоит сверить формулировки с юристами банка: ставки и тарифы в демо условные.
