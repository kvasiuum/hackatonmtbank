# Семья в Moby — хакатон МТБанка «Детско-семейный банкинг»

Кликабельный прототип модуля детско-семейного банкинга внутри Moby для рынка Республики Беларусь.

**Запуск:** откройте `prototype/index.html` в браузере. Сборка и сервер не нужны.

## Режимы
Переключатель слева (на телефоне — сверху). Данные общие для всех ролей и сохраняются в браузере.

- **Родитель:** Moby взрослого, вкладка «Семья», запросы детей, лимиты, категории, доступы, задания, карманные деньги. Добавление ребёнка в 6 шагов: имя и возраст (пакет подбирается сам), согласия, выбор карты (браслет / стикер / пластик, цвет), настройка доступов (режим + отдельные переключатели), вход по QR. У каждого ребёнка до 3 карт: выпуск, блокировка, «карта получена», перевыпуск.
- **Ребёнок 7–13:** карта (стикер/браслет/пластик), «Попросить», симулятор оплаты, копилки с доплатой родителя +10%, задания, уроки, игра «Распознай мошенника», уровни «Крок».
- **Подросток 14–17:** ЕРИП, переводы друзьям, карта для подписок, собственный заработок и вклад (ст. 26 ГК РБ), аналитика трат, путь к 18.

## Сценарии для демо
1. «Начать без детей» → Родитель → «Добавить ребёнка» → настроить доступы → переключиться на «Ребёнок».
2. Родитель → Миша → «Выпустить карту» (браслет / виртуальная).
3. Ребёнок → «Я потерял карту» → оплата проходит виртуальной картой.
4. Ребёнок → «Оплатить» → «Донат в игре» → запрос доступа → Родитель одобряет.
5. Ребёнок → «Магазин игрушек» (дороже 10 BYN) → покупка ждёт подтверждения родителя.
6. Ребёнок → «Задания» → «Сделал!» → Родитель подтверждает → награда и опыт.
7. Ребёнок → «Игры» → уроки / «Распознай мошенника» → новый уровень «Крок» → родителю предложение расширить лимит.

Банковская защита: азартные игры, ставки и товары 18+ закрыты всегда и не отключаются родителем.

Иконки: [Lucide](https://lucide.dev) v0.469.0 (ISC), встроены в файл, поэтому прототип работает без сети.
