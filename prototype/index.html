Семья в Moby

Прототип модуля детско-семейного банкинга для рынка Республики Беларусь. Переключайте роль: изменения общие, так что запрос ребёнка сразу видит родитель.

Сценарии для демо
  1. Ребёнок → «Оплатить» → «Донат в игре»: категория закрыта, запрос уходит родителю.
  2. Ребёнок → «Попросить» 5 BYN → Родитель → «Запросы» → Одобрить.
  3. Ребёнок → «Магазин игрушек»: покупка дороже 10 BYN ждёт подтверждения родителя.
  4. Ребёнок → «Задания» → «Сделал!» → Родитель подтверждает → награда и опыт.
  5. Ребёнок → «Игры» → «Распознай мошенника»: при новом уровне «Крок» родителю приходит предложение расширить лимит.
  6. Подросток → «Платежи» → ЕРИП / перевод другу / подписки.
  7. Родитель → «Добавить ребёнка»: оформление пакета с согласиями.

Концепт-прототип для хакатона. Данные вымышленные, хранятся только в этом браузере.
