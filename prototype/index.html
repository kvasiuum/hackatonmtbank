Семья в Moby

Прототип модуля детско-семейного банкинга для Беларуси. Переключайте роль: данные общие, поэтому запрос ребёнка сразу видит родитель.

Сценарии для демо
  1. Родитель → «Добавить ребёнка»: возраст, согласия, карта, настройка доступов, вход по QR.
  2. Родитель → Миша → «Карты» → «Выпустить карту»: браслет, стикер или виртуальная.
  3. Ребёнок → «Оплатить» → «Донат в игре»: категория закрыта, запрос уходит родителю.
  4. Ребёнок → «Магазин игрушек»: покупка дороже 10 BYN ждёт подтверждения.
  5. Ребёнок → «Я потерял карту»: стикер заблокирован, виртуальная карта продолжает работать.
  6. Ребёнок → «Задания» → «Сделал» → Родитель подтверждает награду.
  7. Подросток → «Платежи»: ЕРИП, перевод другу, подписки.

Концепт-прототип для хакатона. Данные вымышленные и хранятся только в этом браузере.
